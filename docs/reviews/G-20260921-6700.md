# G-20260921-6700 — `review-doc` trial run on FIBR-0155

**Subject:** [`docs/specs/FIBR-0155.md`](../specs/FIBR-0155.md) — native Linux
packaging via the openSUSE Build Service.
**Genre:** `spec` — **interpreted, not declared.** No document in this project
carries a `Genre:` line, which the skill's Step 1 requires.
**Skill:** `review-doc` from `~/.claude/draft/v2/skills/review-doc/`, run as a
live trial at the request of the `~/.claude` workflow-redesign session. Not the
project's standing `review-contract` gate.

## Why this document

It is the rare case that carries a full prior `review-contract` log on itself
(§ 8), so the trial has a same-document baseline rather than an analogy.

| | prior run (§ 8) | this run |
|---|---|---|
| loops | 6 | 1 full + 1 diff-scoped |
| lane dispatches | 18 | 10 |
| verified findings | 58 | 10 |
| outcome | converged at loop 6 | complete |

**The two are not directly comparable, and the confound is large.** The prior
run reviewed the spec *before implementation*, so its population was design
defects. This one ran *after* the packaging shipped, so its population is drift.
Fewer findings here is not evidence of a weaker review.

## Step 2 — the checker

`check-doc.py` returned exit 0 on this document, both before and after the fix
pass. It took **nothing** off the lanes' plate.

That clean result is not what it looks like. The checker's line-reference check
fires only on `<resolvable-path>:<single-line>`. This document's citations are
mostly line ranges (`pyproject.toml:27-65`) or bare module names
(`main_window.py:787`), and both forms skip silently. Of the file:line citations
in this document, roughly a quarter are in the form the checker inspects.

Measured against the prior run: of its 58 findings, the citation-slip class the
checker exists to absorb numbered eight — and every one of them is a bare-name
or range citation, so today's checker would have caught none of them.

Separately, with no `.claude/workflow.json` and no `Genre:` line, the checker
skips `ids`, `lineref`, `path`, `sections`, `symbol` and `version` and still
exits 0.

## What the lanes ran

The `mechanism` lane executed the project's `obs_packaging` suite, `rpmspec -P`
under three macro expansions, `appstreamcli validate`, `desktop-file-validate`,
`shellcheck` over `packaging/obs/*.sh`, the version triangulation across
`__init__.py` / metainfo / `debian/changelog`, and
`QT_QPA_PLATFORM=offscreen python -m finbreak --self-test`. All agreed with the
document.

Could not run, and said so: an OBS submit round, `rpmlint` and
`dpkg-parsechangelog` (neither installed), a local onedir freeze (would write to
the tree), a clean-VM install, a packet capture, and the Leap 15.6 glibc check.

It also reported breaking its own brief: it ran a networked `pip download` after
being told network was out of scope. It flagged that itself rather than omitting
it.

## Cost

`docs/reviews/run-costs.tsv` carries the rows. Per-lane figures are in
`docs/reviews/agent-costs.jsonl`, written by a hook on subagent completion.

**The parent-session figure overstates this review.** It is this session's whole
summed usage over the window, and this session had already drafted two skills
and exchanged several messages before the review began. Most of it is cache
reads of unrelated history.

Cache reads are ~94% of every lane total, so a lane's total is dominated by
context size rather than by review work. Summed across every lane, the tokens
that were not cache reads come to roughly two million.

The `mechanism` lane was by far the most expensive single lane — it runs
commands and reads their output.
