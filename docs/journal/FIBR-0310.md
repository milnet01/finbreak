**The second pattern is its twin: a docstring that certifies behaviour the

still offered"*, and it is not offered on any path. FP03's commits were
heavily docstring-focused, and this is what that costs: the prose records
the intent, and nothing checks it against the code.

beside it that nothing will ever mention. Verified structurally: that error
is raised only from `resume`'s terminal branch, which branch 1 makes
unreachable.
