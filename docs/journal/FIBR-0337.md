## What was fixed

Two HIGH, seven MEDIUM, eight LOW. The two that mattered:

**H1 — data loss.** The resume ladder's branch 2 folded "this replacement is
bad" and "I cannot compare it" into one `False`, then deleted a proven-good
migrated vault on the second. `_replacement_verdict` keeps the three answers
apart; UNCOMPARABLE keeps the copy and refuses rather than falling through.

The design note recorded before the fix was right that the obvious remedy does
not work alone: `_convert` opens S1 with `migrating_db.unlink(missing_ok=True)`,
so a fix that only skips branch 2's unlink loses the file a few frames later.
`mutation_probe` confirms both the original defect and that branch-scoped
near-miss go red against the test, which asserts survival across the whole
`resume` call rather than across branch 2.

**H2 — no exit.** D6 makes Escape and the window [X] no-ops, so the forced
new-password dialog's only way out was `QKeySequence.StandardKey.Quit`, which
resolves through the platform's binding scheme and is Ctrl+Q only under KDE and
Gnome. Both call sites now spell it literally. The defect cannot reproduce on
this machine, so the test stands in a hostile binding scheme instead.

## What was learned

**A fix can make a previously-inert finding material.** Loop 1 of the
security-model gate dismissed a wrong-owner citation as true-but-inert — rule
14's own example of a finding that changes nothing. Loop 1's fix then added a
second citation naming a different owner for the same decision, and all three
loop-2 lanes filed it. The dismissal was correct when made and wrong an hour
later, because of the fix.

**Lanes catch the orchestrator's errors when the packet states facts.** Two
security-model lanes independently disputed a packet fact — that
`validate_untrusted_params` bounds all three axes on both sides; it caps
`memory_kib` on the high side only — and both declined to file it against the
document, one saying outright not to correct the document toward the packet.
The loop-2 fix had inherited that error, and the dispute is what found it.

**The defect shape is a design property, not an accident.** FP02, FP03 and
FP04 each recorded it; FP05 found four instances in one pass (H1, M1, M5, L4).
The ladder's helpers return two-valued answers to three-valued questions and
their callers act destructively on the merged result. `_replacement_verdict` is
the first to name the third answer. FIBR-0339 carries the rest.
